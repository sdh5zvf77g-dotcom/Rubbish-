# Aether – Lifelong AI Companion (2027)

**Private • On-device first • Built for everyone**

A high-fidelity interactive mobile web prototype of Aether, designed as a product-ready experience for the 2027 market.

## What’s New in This Version

- Completely redesigned **Home Dashboard** with Pulse score, priorities, learning snapshot and clear quick actions
- Smoother navigation and more consistent visual hierarchy
- Improved Agent chat with better message styling
- Full working flows: Capture, Research, Knowledge Graph, Health, Learning Paths, Settings
- Accessibility toggles (large text + high contrast)
- Light / Dark theme
- PWA manifest (installable feel)
- Cleaner empty states and feedback (toasts)
- Error-checked interactions

## How to Run

1. Open `index.html` directly in any modern browser, **or**
2. Serve locally for best experience:

```bash
cd aether-app
python3 -m http.server 8080
```

Then open `http://localhost:8080` (use mobile emulation or a phone on the same network).

## Positioning (Why it can win in 2027)

- **Personal Knowledge Graph** – everything you capture becomes a living, queryable graph you own
- **Agentic cross-domain actions** – one request can research + plan + schedule + budget
- **On-device first** – privacy as a core product promise
- **Accessibility as foundation** – not an afterthought
- **Lifelong continuity** – designed to compound over years, not just sessions
